Essential Query Reference

CPU Utilization per Host
SRE
// Average CPU usage across all cores, 5m window
100 - (avg by (instance) (
  rate(node_cpu_seconds_total{
    mode="idle"
  }[5m])
) * 100)
Kafka Consumer Lag
Data Eng
// Total lag across all partitions per consumer group
sum by (consumergroup, topic) (
  kafka_consumergroup_lag{
    topic!="__consumer_offsets"
  }
)
API Error Rate (RED)
Backend
// % of requests returning 5xx errors, 1m rate
sum(rate(http_requests_total{
  status=~"5.."
}[1m])) /
sum(rate(http_requests_total[1m]))
* 100

Database
// Ratio of cache hits vs disk reads — target >99%
sum(pg_stat_bgwriter_buffers_clean) /
(
  sum(pg_stat_bgwriter_buffers_clean) +
  sum(pg_stat_bgwriter_buffers_backend)

SRE / K8s

Setup

Getting Started in 5 Steps

01
Install Grafana
Deploy Grafana via Docker or Helm. Use the official Grafana Helm chart for Kubernetes environments.
helm install grafana grafana/grafana
02
Add Prometheus
Configure Prometheus as your primary data source. Enable remote_write for long-term storage if needed.
datasources: prometheus:9090
03
Import Dashboards
Use the Grafana UI or API to import community dashboards by ID from grafana.com/grafana/dashboards.
POST /api/dashboards/import
04
Deploy Exporters
Install node_exporter, kube-state-metrics, and any service-specific exporters as DaemonSets or sidecars.
kubectl apply -f exporters/
05
Configure Alerts
Set Grafana alerting rules or Prometheus alerting rules with Alertmanager routing to PagerDuty/Slack.
alerting: rules/*.yaml
